# Counter diagram for the project-files lesson

`counter-event-model.json` is the supplied diagram for the English Find your project files lesson. It is not claimed to be generated automatically by `neo new`.

The nodes, fields, and connections were derived with `neo inspect sync` from the actual Counter starter generated by Neo 0.18.0, pinned to [NeoHaskell revision 414602b9510a92dfac647bc68d6afadfb594502c](https://github.com/neohaskell/NeoHaskell/tree/414602b9510a92dfac647bc68d6afadfb594502c/neo/starter). The feature, chapter, and slice names and ordering were matched to `src/Starter/Counter/Feature.hs`. The entity label matches `CounterEntity`. Positions were adjusted to keep each command above its event.

The diagram was validated with the release CLI's `neo validate` and opened through its bundled `neo ide`. The documentation screenshots show that real dark interface. This diagram provides a starting point for inspection; it does not implement behavior or replace source code.
